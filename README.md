## Favicon (browser icon)

The project uses a soft green ecology-themed leaf favicon.

**Files:**
- `public/favicon.svg` — main favicon (SVG, used by modern browsers)
- `public/favicon.ico` — fallback ICO (16/32/48/64 px, for older browsers)
- `public/favicon.png` — 64×64 PNG version

**How to replace the favicon:**
1. Prepare your own image (recommended: 64×64 or larger, square).
2. Replace `public/favicon.svg` (and optionally `public/favicon.ico`) with your new file, **keeping the same filename**.
3. The `<link rel="icon">` tags in `index.html` already point to these paths — no code change needed.
